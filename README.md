# zh 文章屏蔽器

一个 Tampermonkey 用户脚本，在 zh 首页/热榜/专栏广场/圈子动态自动屏蔽非技术文章。

## 浏览器与插件

- **浏览器**：Chrome / Edge / Firefox 等支持用户脚本的浏览器
- **插件**：Tampermonkey（油猴扩展）

## 功能

- **18 分类多选屏蔽**：勾选要屏蔽的分类（情感、娱乐、养生、政治等），命中关键词即屏蔽
- **问题正则兜底**：未命中分类时用正则匹配提问式标题（"怎么评价""为什么"等）
- **默认屏蔽**：未命中任何规则的标题默认屏蔽，只放行命中技术关键词的文章
- **作者黑/白名单**：按作者精确屏蔽或放行
- **屏蔽私信未读提示**：隐藏 zh 私信入口的未读数字（可开关）
- **拦截先于渲染**：卡片插入时立即隐藏，判定后才显示，避免内容闪现
- **远程规则同步**：分类关键词和问题正则从 GitHub 拉取，6 小时自动同步
- **配置导出/导入**：跨设备同步规则（覆盖式）
- **调试模式**：放行文章也标记命中原因，便于核对规则是否误杀

## 安装

1. 安装 Tampermonkey 浏览器扩展
2. 浏览器访问下方 URL，Tampermonkey 识别 `.user.js` 并弹出安装确认：

```
https://raw.githubusercontent.com/imenk2/zhihu-shield/main/zhihu-tech-filter.user.js
```

3. 确认安装，打开 zh 即生效

## 更新

脚本头部含 `@updateURL` / `@downloadURL`，Tampermonkey 定期检查版本号自动拉取更新。发版时递增 `@version` 并推送即可。

## 配置

页面右下角悬浮图标 → 设置面板，可编辑：
- 未命中规则时的默认行为（放行/屏蔽）
- 屏蔽私信未读提示开关
- 调试模式开关
- 屏蔽分类勾选
- 屏蔽问题正则（每行一个）
- 作者黑/白名单、技术/非技术关键词
- 配置导出/导入

## 判定顺序

作者黑名单 > 作者白名单 > 分类判定 > 问题正则 > 默认行为

关键词子串匹配，不区分大小写。
